# 캡컷 프로젝트 여는 법 (PC용 CapCut)

1. `page_people_책추천` 폴더를 통째로 캡컷 프로젝트 폴더에 복사합니다.
   - Windows: `C:\Users\<사용자이름>\AppData\Local\CapCut\User Data\Projects\com.lveditor.draft\`
   - Mac: `~/Movies/CapCut/User Data/Projects/com.lveditor.draft/`
   - 위치를 모르겠으면 캡컷 설정 → "초안 위치(Draft location)"에서 확인할 수 있습니다.
2. 캡컷을 껐다 켜면 홈 화면에 `page_people_책추천` 프로젝트가 보입니다.
3. 미디어가 빨간색(누락)으로 뜨면, 누락된 클립을 클릭하고 "미디어 연결/재연결"에서 `page_people_책추천/media` 폴더를 고르면 한 번에 연결됩니다.

## 트랙 구성
| 트랙 | 내용 |
|---|---|
| 본영상 | final_cut.mp4 (컷편집·음량·색 보정 완료본, 소리 포함) |
| 책 사진 | 임시 이미지 4장. 클릭 → "교체"로 실제 책 사진으로 바꾸기 |
| 대사 자막 | subtitles.srt 52줄 (흰 글씨 + 검은 테두리 기본값) |
| 강조 자막 | 유퀴즈식 노란 자막 11개 (edit_notes.md 3번 표 기준) |
| 후킹·엔딩 | 0~1.2초 후킹 문구, 마지막 1.7초 `page ⇄ people` |

## 프로젝트가 안 열릴 때
캡컷 최신 버전은 프로젝트 파일 형식을 바꾸기도 해서, 외부에서 만든 프로젝트를 못 읽는 경우가 있습니다.
그럴 땐 새 프로젝트에 `final_cut.mp4`를 넣고, 텍스트 → "자막 가져오기(Import captions)"로 `subtitles.srt`를 불러오면 같은 상태가 됩니다.
모바일 캡컷은 프로젝트 파일과 SRT를 불러올 수 없어서 `final_cut.mp4`만 넣고 "자동 자막"을 쓴 뒤 edit_notes.md를 보며 고치면 됩니다.
