# 감성 인터뷰 캡컷 프로젝트 (질문 포함 버전, 59.73초) (page_people_감성인터뷰_질문포함)

## 여는 법
1. `page_people_감성인터뷰_질문포함` 폴더를 통째로 캡컷 프로젝트 폴더에 복사합니다.
   - Windows: `C:\Users\<사용자이름>\AppData\Local\CapCut\User Data\Projects\com.lveditor.draft\`
   - Mac: `~/Movies/CapCut/User Data/Projects/com.lveditor.draft/`
2. 캡컷을 다시 켜면 홈에 프로젝트가 보입니다.
3. 미디어가 빨갛게(누락) 뜨면 "미디어 연결"에서 `page_people_감성인터뷰_질문포함/media` 폴더를 고르면 됩니다.
4. 프로젝트가 아예 안 열리면: `final_interview_with_questions.mp4`(자막 입힌 완성본)를 바로 쓰거나, `media/interview_clean.mp4`(자막 없는 버전)에 직접 글씨를 올리면 됩니다.
